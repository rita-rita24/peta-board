# PetaBoard

個人の仕事・タスクを付箋で整理する、ローカルHTMLのボードです。タイトル・本文・タグ・期限・チェックリストを使い、列ごとに作業をまとめられます。アカウント登録は不要です。

## 使い方

1. `PetaBoard.html` をブラウザーで開き、各列の「付箋を追加」から書き始めます。何も書かずに編集画面を閉じた付箋は残りません。
2. 列名はクリック、ボード名は設定から変更できます。付箋はドラッグか編集画面の「移動先の列」で移動します。タッチでは右上のハンドルを使い、カード上のスワイプで一覧をスクロールできます。
3. 検索はタイトル・本文・タグ・チェック項目・列名が対象です。スペース区切りで絞り込み、結果件数を確認できます。検索中に付箋を追加すると、作った付箋を見失わないよう検索を解除します。ボード上の `/` で検索へ移動、`Esc` で検索解除や編集画面を閉じられます。
4. 列・付箋・チェック項目を削除しても、30秒以内なら「元に戻す」で復元できます。連続した削除も猶予内なら順に戻せます。復元の猶予はこの画面を開いている間に限り、ボードの読み込み・初期化・別タブの更新反映時には終了します。`Tab` で付箋を選び、`Enter` で編集できます。列の並べ替えには左右の矢印も使えます。

列はすべて削除できます。0列の状態も保存され、「列を追加」から再開できます。

画面上の「使い方」は、基本操作・保存・バックアップ・ショートカットの説明だけを独立して表示します。ボード名、テーマ、初期色、読み込み、初期化は「設定」にまとめています。表示は常にコンパクトです。

## 保存とバックアップ

変更はこの端末の、このブラウザー内へ自動保存します。自動保存中の表示は出さず、保存の停止や復旧など、お知らせが必要な状態を画面上部に表示します。HTMLファイル自体への書き込みやクラウド同期はありません。

「バックアップ」でボード全体をJSONとして書き出せます。復元は設定の「読み込み」から行い、確認後に現在のボードを置き換えます。閲覧データの削除、端末・ブラウザーの変更、HTMLの移動・名前変更前に書き出してください。プライベートブラウズ終了時などに保存データが失われる場合もあります。

自動保存にはWeb Locksを利用できる環境が必要です。ローカルHTML、HTTPS、開発用のlocalhostで開いてください。保存失敗や複数タブの編集競合時は上書きを停止し、現在の内容の書き出し・再試行・保存済み内容の再読み込みを案内します。異常な保存データは既存の退避を保護し、次の保存が成功するまで元の原文も保持します。

JSON読み込みは32MiBまで、列12件・付箋500件までです。内容の切り捨てが必要なJSONは読み込みを拒否します。ブラウザーの保存容量は別の制限となり、容量不足時は画面に通知します。

## 開発・検証

HTML・CSS・JavaScriptは `PetaBoard.html` にまとめ、ビルド不要で直接開ける構成です。CSSはレイアウト・操作状態、業務UIの共通部品、アプリ固有の調整の順に定義しています。関連する子要素や状態はブラウザー標準のCSSネスト構文でまとめ、画面幅による上書きはレイアウト・アプリ固有のスタイルシートの末尾に置いています。利用にはCSSネスト構文に対応した現行ブラウザーが必要です。

ダイアログの背景・パネル・開閉状態は共通CSSにまとめ、サイズと重なり順は各画面で指定しています。付箋のクリック・キー・ポインター操作は常設のボード要素で受け取り、再描画のたびにイベントリスナーを登録し直さない構成です。読み込みと別タブ同期のデータ検証は共通の検証関数を通します。

Node.jsとnpmを用意し、次を実行します。

```sh
npm ci
npx playwright install chromium
npm test
npm run lint
```

`npm test` はChromiumの回帰テスト、`npm run lint` はインラインJavaScriptの構文確認です。Firefox・WebKitも確認する場合は、次を実行します。

```sh
npx playwright install firefox webkit
npm run test:cross-browser
```

クロスブラウザーテストは、日本語入力・チェックリスト・保存と再読み込み・JSONバックアップ復元・375px幅の編集を検証します。PlaywrightのWebKit検証は、Safari実機の確認を置き換えるものではありません。

`PETA_TEST_BROWSERS=firefox,webkit npm test` で実行対象を変更できます。既存のブラウザーを使う場合は `PETA_TEST_CHROMIUM_EXECUTABLE_PATH`、`PETA_TEST_FIREFOX_EXECUTABLE_PATH`、`PETA_TEST_WEBKIT_EXECUTABLE_PATH` に実行ファイルのパスを指定します。`PETA_BOARD_HTML` で検証対象HTMLも指定でき、テスト・構文確認・カバレッジ・ミューテーション検証で共通して使われます。相対パスはコマンドの実行ディレクトリを基準に解決します。
